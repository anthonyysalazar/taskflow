# TaskFlow

¡Hola! Este es TaskFlow, una aplicación web que estoy desarrollando como proyecto de DAW.

La idea del proyecto es crear una herramienta sencilla para organizar las tareas del día a día, poder controlar cuáles están pendientes y cuáles ya se han terminado.

## ¿Qué se puede hacer?

- Añadir tareas nuevas.
- Marcar tareas como completadas.
- Volver a abrir tareas que ya están completadas.
- Eliminar tareas.
- Elegir la prioridad de cada tarea (baja, media o alta).
- Añadir una fecha límite.
- Buscar tareas por su nombre.
- Filtrar entre tareas pendientes y completadas.
- Ver estadísticas y el progreso de las tareas.

## Tecnologías que he utilizado

Para desarrollar el proyecto he utilizado:

- HTML para la estructura de la página.
- CSS para el diseño y los estilos.
- JavaScript para las funcionalidades.
- Node.js para ejecutar el servidor.
- Express para gestionar las rutas y las peticiones.
- SQLite para guardar las tareas.
- Git y GitHub para guardar las diferentes versiones del proyecto.

## Cómo ejecutar el proyecto

Si quieres probar la aplicación en tu ordenador, sigue estos pasos:

1. Descarga o clona este repositorio:

   `git clone https://github.com/anthonysalazar/taskflow.git`

2. Entra en la carpeta del proyecto:

   `cd taskflow`

3. Instala las dependencias:

   `npm install`

4. Arranca el servidor:

   `node server.js`

5. Abre el navegador y entra en:

   `http://localhost:3000`

## Carpetas y archivos

- `public`: contiene los archivos de la parte visual de la aplicación.
- `capturas`: contiene imágenes del desarrollo y de las pruebas.
- `database.js`: se encarga de la conexión y configuración de la base de datos.
- `server.js`: contiene el servidor y las rutas de la aplicación.
- `package.json`: contiene la información y las dependencias del proyecto.
- `.gitignore`: indica qué archivos no se deben subir a GitHub.
